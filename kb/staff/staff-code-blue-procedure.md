## What Code Blue means
Code Blue is the hospital-wide alert for a patient or visitor who has collapsed and is unresponsive. This document describes the alert logistics only. Clinical steps follow the training you received in basic life support.

## How to raise the alert
1. Stay with the person and shout for help.
2. Have another person dial ext. 2222, the Code Blue line, from the nearest phone. It is answered by the switchboard 24 hours a day.
3. Say clearly: "Code Blue", the building, floor, room or area name.
4. The switchboard announces the code on the public address system and pages the team.

## Team and response time
The Code Blue team comprises one duty doctor, one ICU nurse, one ward nurse, one respiratory technician, one security guard and one porter. The team must arrive within 3 minutes of the call in the Main Block and within 5 minutes in the OPD Block or the Mother and Child Wing.

## Roles on arrival
- Team leader (duty doctor): directs the response.
- Recorder (ward nurse): notes the time of the call, arrival and actions on the Code Blue form.
- Crash cart carrier (porter): brings the red crash cart from the nearest station.
- Security: clears the way, holds the lift, and keeps onlookers away.

## Crash cart stations
Red crash carts are kept in the Emergency department, ICU, each ward floor of the Main Block, the OPD Block 1st floor, and the Mother and Child Wing 2nd floor. Nurses check each cart's seal and log every shift.

## After the event
- The recorder submits the form to the Quality department (ext. 2330) within 24 hours.
- An incident report is filed as per the incident reporting document.
- A debrief is held within 48 hours, led by the ICU in charge on ext. 2130.
- Drills are run every month, with a different location each time.
